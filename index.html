Password Vault

A password manager that never leaves the machine. Shortcut autofill, save-on-login, and Touch ID unlock via the WebAuthn PRF extension — the Secure Enclave returns a secret that wraps the vault's AES key, so the wrapped key on disk is useless without the authenticator. No account, no sync, no servers, no dependencies.

React If Directive

Conditional rendering as attributes — r-if, r-else-if and r-else sit on the element itself instead of nesting ternaries inside JSX. A Vite plugin rewrites them to standard React at build time, so nothing ships at runtime, with an ESLint plugin that flags broken chains in the editor and TypeScript types for autocomplete.
